Prompts utilizados

Prompt 1.
Antes de escribir código, ayúdame a descomponer el problema. Si un estudiante solicita un saludo, ¿qué datos mínimos debe pedir el sistema y en qué orden conviene solicitarlos para que el flujo sea claro?

Prompt 2.
Si el sistema ya conoce nombre y edad, ¿qué información debería incluir el mensaje final para que el estudiante se sienta identificado? Justifica por qué esos datos sí deben aparecer y cuáles podrían quedar solo como entrada.

Prompt 3.
El sistema pide hora. Si únicamente se usa AM o PM, ¿qué se pierde? Propón una forma de pedir la hora numérica y el periodo AM/PM sin confundir al usuario.

Prompt 4.
No me des aún el programa completo. Pregúntame qué decisiones de interfaz debo tomar: ¿un solo formulario visible desde el inicio o un botón que revele los campos después de solicitar el saludo?

Prompt 5.
Con las decisiones anteriores, genera una versión en HTML, CSS y JavaScript. El programa debe: mostrar un botón de solicitar saludo; pedir nombre, edad, hora (1 a 12) y AM/PM; y saludar mencionando nombre, edad y hora. Explica brevemente qué hace cada parte.

Prompt 6.
Revisa esta interfaz como si fueras el usuario. ¿Qué elementos visuales dificultan la lectura o el uso? Sugiere mejoras de diseño sin cambiar la lógica del flujo.

Prompt 7.
Ajusta el código para que se vea más claro: tarjeta centrada, botones distinguibles y un recuadro para el resultado. Conserva las validaciones de los campos obligatorios.

Prompt 8.
Verifica con este caso de prueba: nombre Ana, edad 18, hora 9, AM. ¿El mensaje final es coherente? Si no, corrige solo la construcción del texto de salida.

Prompt 9.
Redacta, en lenguaje sencillo, las instrucciones de ejecución para alguien que no sabe programar.
